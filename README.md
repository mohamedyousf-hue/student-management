\# Student Management System



A full-stack Student Management System built to practice backend development, containerization, and Kubernetes deployment.



\## 🚀 Project Overview



This project provides a web-based dashboard for managing students and viewing basic statistics.



The application consists of:



\- Frontend dashboard

\- FastAPI backend

\- SQLite database

\- REST API

\- Docker containers

\- Kubernetes deployments and services



\## 🛠️ Technologies



\### Frontend

\- HTML5

\- CSS3

\- JavaScript



\### Backend

\- Python

\- FastAPI

\- Uvicorn

\- SQLAlchemy

\- Pydantic



\### DevOps

\- Docker

\- Kubernetes

\- Git

\- GitHub



\### Database

\- SQLite



\## ✨ Features



\- View students

\- Search students by name or department

\- Add new students

\- Delete students

\- View student status

\- View total number of students

\- View departments

\- Display students by department

\- RESTful API

\- Dockerized frontend and backend

\- Kubernetes Deployments and Services
